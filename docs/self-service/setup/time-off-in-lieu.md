**How much time off in lieu does each person hold, and when does it lapse?**

**Where:** My HR → Self Service → Setup → TOIL Balances · **Who can run it:** HR User, HR Manager, System Manager, Leave Approver (an approver sees the staff whose claims they can see).

## Filters

| Filter | Use it to |
|:---|:---|
| **Company** | Only this company's staff. |
| **Employee** | One person. |
| **Time Left Only** | Only people with time still to use (ticked by default). |

## Columns

| Column | Shows |
|:---|:---|
| **Employee**, **Name** | The person. |
| **Earned (days)** | Time off from their approved claims. |
| **Used**, **Lapsed Unused**, **Left** | Taken, lapsed and still usable. |
| **Lapsing in 30 Days** | Time that lapses within 30 days. |
| **Next Lapse** | When the next claim's time lapses. |

## Reading it

Use **Lapsing in 30 Days** to remind people to book their time off before it lapses. See [Time Off in Lieu Claim](../time-off-in-lieu-claim.md).
