**What does each employee contribute to NSSF this month?**

**Where:** My HR → search bar → **Kenya NSSF Register** (no sidebar entry) · **Who can run it:** HR User, HR Manager.

## Filters

| Filter | Use it to |
|:---|:---|
| **Company** | The company's salary slips. |
| **Start Date**, **End Date** | The period (required; by default the last month). |
| **Currency** | The currency to show. |
| **Document Status** | **Submitted** by default; **Draft** checks a payroll before you submit it. |
| **Salary Component** | The NSSF deduction (required; starts as Employee NSSF). |

## Columns

| Column | Shows |
|:---|:---|
| **Payroll No**, **Surname**, **Other Names** | The employee. |
| **National ID**, **KRA PIN**, **NSSF No** | From the employee record. |
| **Gross Pay** | From the salary slip. |
| **Amount** | The contribution. |

## Reading it

This is the monthly NSSF return. An empty register usually means **Salary Component** does not match the name your salary structures use. A blank **NSSF No** needs filling on the employee record.
