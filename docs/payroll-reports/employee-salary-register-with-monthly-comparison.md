**How did each employee's gross pay change from last month?**

**Where:** My HR → search bar → **Employee Salary Register With Monthly Comparison** (no sidebar entry) · **Who can run it:** HR User, HR Manager.

## Filters

| Filter | Use it to |
|:---|:---|
| **From**, **To** | The period (required). The month compared is the month of **From**, set against the month before. |
| **Company** | Required. |
| **Currency**, **Employee**, **Department** | Narrow the report. |
| **Document Status** | **Submitted** by default. |

## Columns

| Column | Shows |
|:---|:---|
| **Employee**, **Employee Name**, **Department** | The employee. |
| Gross pay | For each month. |
| **Gross Difference Amount** | This month minus last. |

## Reading it

A large **Gross Difference Amount** for one person points to the slip to check before you pay.
