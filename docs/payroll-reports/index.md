**Seven payroll reports built from your salary slips: the Kenyan statutory registers, the bank advice, and two month-on-month comparisons.**

No sidebar lists them; type each one's name in the search bar. **HR User** and **HR Manager** can run them. The [Kenya Salary Register](kenya-salary-register.md) also shows only the salary slips you may open in the Salary Slip list. The registers read each employee's **National ID**, **KRA PIN**, **SHA No.** and **NSSF No.**: see [Employee details](../self-service/employee-details.md).
