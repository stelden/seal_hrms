**What should the bank pay into each employee's account?**

**Where:** My HR → search bar → **Payroll Bank Advice** (no sidebar entry) · **Who can run it:** HR User, HR Manager.

## Filters

| Filter | Use it to |
|:---|:---|
| **Company** | The company's salary slips. |
| **Start Date**, **End Date** | The period (required; by default the last month). |
| **Currency** | The currency to show. |
| **Document Status** | **Submitted** by default; **Draft** checks a payroll before you submit it. |
| **Bank** | One bank's payments. |

## Columns

| Column | Shows |
|:---|:---|
| **Employee ID**, **Employee Names**, **National ID** | The employee. |
| **Bank Name**, **Account No**, **Branch** | Where to pay. |
| **Amount** | Net pay. |

## Reading it

Send it to the bank with the payment instruction. A blank **Account No** needs a bank account on the employee record: see [Employee details](../self-service/employee-details.md).
