**What did each salary slip in the period pay and deduct?**

**Where:** My HR → search bar → **Kenya Salary Register** (no sidebar entry) · **Who can run it:** HR User, HR Manager.

## Filters

| Filter | Use it to |
|:---|:---|
| **Company** | The company's salary slips. |
| **Start Date**, **End Date** | The period (required; by default the last month). |
| **Currency** | The currency to show. |
| **Document Status** | **Submitted** by default; **Draft** checks a payroll before you submit it. |
| **Employee** | One employee. |

## Columns

| Column | Shows |
|:---|:---|
| Employee and statutory numbers | One row per salary slip. |
| Each earning and deduction | A column per salary component on the slips. |
| **Gross Pay**, **Total Deduction**, **Net Pay** | The totals. |
| Bank details | Where the pay goes. |

## Reading it

This is the full monthly register. Compare it with [Salary Register Summary With Monthly Comparison](salary-register-summary-with-monthly-comparison.md) to explain changes.
