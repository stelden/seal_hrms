**How did each department's pay, component by component, change from last month?**

**Where:** Self Service → search bar → **Salary Register Summary With Monthly Comparison** (no sidebar entry) · **Who can run it:** HR User, HR Manager.

## Filters

| Filter | Use it to |
|:---|:---|
| **From**, **To** | The period (required). The month compared is the month of **From**, set against the month before. |
| **Company** | Required. |
| **Currency**, **Employee**, **Department** | Narrow the report. |
| **Document Status** | **Submitted** by default. |

## Columns

| Column | Shows |
|:---|:---|
| **Department**, **Salary Component** | The grouping. |
| Employees, gross pay and each component | For both months. |
| **Difference Amount** | This month minus last. |

## Reading it

Explain every non-zero **Difference Amount** before you pay: a new joiner, a leaver, a rise or a one-off.
